# Nexus Decisions

## ADR-001
Modular monolith + plugin runtime.

## ADR-002
pnpm workspace monorepo.

## ADR-003
Fastify backend.

## ADR-004
Vue 3 + Vite frontend.

## ADR-005
SQLite for metadata/state.

## ADR-006
SQLite WAL mode.

Redis + BullMQ for long-running jobs.

## ADR-008
Tus for resumable uploads.

## ADR-009
SSE for realtime events.

## ADR-010
Mature OSS implementations are reused before custom implementation.

## ADR-011
Plugins must not depend on Core internals.

## ADR-012
Nexus is private, single-user and self-hosted.
