# Nexus Product

## Definition

Nexus is a private, single-user, self-hosted personal utility application.

It brings many everyday utility workflows into one private interface instead of requiring the owner to use many external websites.

Examples:

- conversion
- PDF operations
- QR generation
- archive handling
- image/media processing

## Core Value

One application for the owner's everyday utility tasks.

Files, history and metadata remain on the owner's hardware.

Nexus is not designed as a SaaS product.
It does not depend on:

- advertising
- free-tier limits
- subscriptions
- third-party processing

The practical limits are the owner's hardware and storage.

## Processing Philosophy

Nexus integrates proven software.

Examples:

- FFmpeg
- Pandoc
- LibreOffice
- 7-Zip
- ImageMagick
- other mature OSS tools

Nexus provides:

- interface
- orchestration
- storage
- jobs
- progress
- cancellation
- history
- plugin integration

The processing engine remains the responsibility of the appropriate mature tool/library.

## UX

Nexus is:

- mobile-first
- minimal
- touch-friendly
- whitespace-heavy
- icon-oriented
- low-noise

Minimum touch target: 44px.
Advanced options should use progressive disclosure.

## Access

Primary clients:

- phone
- tablet
- desktop

The application may be accessed through:

- LAN
- Tailscale
- secured remote access

## Product Principle

One website.

My hardware.

My files.

My tools.

My data.
