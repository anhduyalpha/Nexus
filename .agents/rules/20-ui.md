# Nexus UI Rules

Apply only to frontend/UI work.

## Stack

- Vue 3
- Vite
- TypeScript
- Tailwind CSS
- shadcn-vue
- Lucide

## Visual language

Nexus uses an extremely minimal interface.

Prefer:

- large whitespace
- restrained typography
- thin borders
- minimal decoration
- icon-first interaction
- progressive disclosure

Avoid:

- unnecessary cards
- excessive shadows
- gradients
- decorative effects
- long instructional text
- unnecessary tooltips

## Interaction

- Mobile-first.
- Minimum touch target: 44px.
- Must work on phone, tablet and desktop.
- Keep primary actions visually obvious.

## Design

Use Stitch MCP when the task requires UI generation, exploration or visual prototyping.
Reuse existing Nexus design tokens/components before creating alternatives.
