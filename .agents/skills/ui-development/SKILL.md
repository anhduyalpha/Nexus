# Nexus UI Development

Read:

- `docs/PRODUCT.md`
- `.agents/rules/20-ui.md`

Use existing Nexus components first.

For new UI:

- mobile-first
- 44px minimum touch targets
- minimal visual noise
- progressive disclosure
- accessible semantics

Use Stitch MCP when the task explicitly requires screen/design generation.
